# Public Source Snapshot Policy

## 목적

이 저장소의 목적은 개발 중인 게임 전체를 배포하는 것이 아니라, 포트폴리오 검토자가 다음 내용을 확인할 수 있게 하는 것입니다.

- 문제를 어떤 책임 단위로 나누었는가
- 상태·그래프·AI 노드·풀링 수명주기를 어떻게 모델링했는가
- 프리뷰 판정과 실제 상태 변경을 어떻게 분리했는가
- GC와 물리 쿼리 비용을 줄이기 위해 어떤 선택을 했는가
- 외부 에셋과 프로젝트 코드 사이에 어떤 Adapter/Boundary를 두었는가

## 포함 범위

- 세 개의 대표 Gameplay 시스템에서 선별한 C# 소스
- 시스템별 README와 아키텍처 문서
- 외부 및 프로젝트 전용 의존성 목록
- 공개 저장소의 인코딩·중복·링크 상태를 확인하는 검증 스크립트
- GitHub Actions 기반 공개본 위생 검사

## 의도적으로 제외한 범위

| 제외 항목 | 제외 이유 |
|---|---|
| Unity Scene, Prefab, `.asset`, ProjectSettings | 전체 게임 구조와 콘텐츠가 노출되며 코드 검토에 필수적이지 않음 |
| 모델, 텍스처, 애니메이션, VFX, UI, 사운드 | 제작 중인 게임 자산 및 라이선스 보호 |
| 전체 Manager/Controller/Service 코드 | 공개 샘플의 경계를 넘어 프로젝트 전체 구조가 노출될 수 있음 |
| 유료 또는 외부 패키지 | 재배포 권한이 없으며 원 저작권자에게 권리가 있음 |
| 빌드 파일과 플레이 가능한 데모 | 이 저장소의 목적이 실행 배포가 아니라 소스 검토이기 때문 |
| 일부 데이터 클래스와 전용 설정 에셋 | 실제 밸런스·콘텐츠 데이터와 프로젝트 내부 결합을 분리하기 위함 |
